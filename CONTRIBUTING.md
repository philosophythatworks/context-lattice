# Contributing

Issues, questions about the paper, benchmark reproduction reports, and architectural discussions are warmly welcome on GitHub Issues in Korean or English.

Code pull requests are not accepted at this stage so that the dual-licensing structure ([AGPL-3.0-only](LICENSES/AGPL-3.0-only.txt) + commercial licence) remains under a single copyright holder without requiring a Contributor Licence Agreement (CLA). If you spot a bug or want to suggest an improvement to the coordinate engine or paper, please open an issue describing it.
