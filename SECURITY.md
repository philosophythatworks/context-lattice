# Security Policy

`context-lattice` is a zero-dependency pure JavaScript coordinate engine (`src/coord/`), benchmark suite (`benchmark/`), and research paper package (`paper/`). It does not open network connections or execute external shell commands.

If you discover a security issue (for example, pathological input causing catastrophic regex backtracking in `notation.mjs` or `lint.mjs`), please report it privately through GitHub's **Report a vulnerability** tab or via <https://philosophythatworks.com/>.
